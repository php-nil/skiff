安全边界

1. 每个账号 chroot 到所属站点的 index/，看不到 conf/、log/、ssl/， 也到不了别的站点。
2. 账号文件身份与该站点 PHP 容器内 www-data 一致（官方 alpine 镜像为 82:82）， 上传文件 owner 为 82、目录 2775、文件 0664，PHP 进程可直接读写。
3. 并发连接上限与每 IP 上限可在「服务配置」中调整（默认 30 / 3）；fail2ban 专用 jail 对 pure-ftpd 认证失败执行 3 次 / 10 分钟封禁，可在同一配置里开关，关闭不会卸载 fail2ban 软件包。
4. 监听端口与被动端口范围都可改，改后需在宿主防火墙同时放行；插件不修改宿主防火墙，避免越权。
5. 服务配置由内核 /etc/skiff/ftp-service.json 持久化，重装/升级后沿用； 插件本地不再保留 service-config.json，避免双份真相漂移。

回收

停用前请确认没有业务仍在使用 FTP。删除账号不会删除已上传的文件。
fail2ban 是宿主系统包，不是内核内置：首装时与 pure-ftpd 一起安装并写入专用 jail。 停止回收只删除本插件的 jail 文件并重启 fail2ban，不会卸载 fail2ban 软件包。
