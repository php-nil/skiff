网站类型

运行环境适合 PHP / Node.js / Go 应用；静态站只托管构建产物；反向代理把请求转发到已有上游。

运行环境类型
P1 只提供 PHP 运行环境
Node.js / Go 在 P1 不提供建站。本轮只定义模型与信息架构，不安装运行时、不启动进程、不分配端口。 可以查看 P2 设计态的 Node/Go 环境详情，但向导提交按钮保持禁用。

填写域名与目录；运行环境站点会绑定上一步选择的运行环境。

用于 vhost 与站点目录命名；必须全实例唯一。

逗号或空格分隔；不能与其他站点的主域名/别名冲突。

必须是 /www/sites/ 的一级子目录；留空时按主域名自动生成。
