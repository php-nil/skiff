### 首次按 Release 资产装机发现并修复的问题

- `Umask` 原先写成 `002:002`：Debian `pure-ftpd-wrapper` 只接受两个空白分隔的三位八进制数
  （`^([0-7]{3})\s+([0-7]{3})$`），冒号形式会让 `pure-ftpd` 启动直接退出 255。改为 `002 002`。
- `pure-pw` 路径原先写死 `/usr/sbin`：Debian/Ubuntu 实际在 `/usr/bin/pure-pw`，建号/改密/删号
  全部失败（`systemd-run` 报 `Failed to find executable /usr/sbin/pure-pw`）。改为按
  `/usr/bin` → `/usr/sbin` 顺序探测，找不到时报明确错误；格式与路径选择均有单测覆盖。
- 认证链原先只写 `conf/PureDB`，没有建 `/etc/pure-ftpd/auth/50pure` 符号链接；包自带的
  `65unix` / `70pam` 让虚拟账号先走 PAM，登录直接 530（`pam_unix: user unknown`）。
