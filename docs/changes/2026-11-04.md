## 默认站点：库状态 + 代码生成 conf（v4）

原先把测试机裸访问（`IP:8080`）指向演示站是手写 `00-skiff-default.conf`；本轮收进内核。
`is_default` 存在 `sites` 表（schema v4 加列 + `is_default=1` 的部分唯一索引），状态只认库，
conf 文件是投影，不再用文件存在与否当状态来源。

- 网站列表新增「默认」列与「设为默认 / 取消默认」按钮（POST `/{p}/sites/{domain}/default`，
  管理角色 + CSRF + 审计 `sites.default`）。
- 有默认站点时由代码生成 `00-skiff-default.conf`（`default_server` 指向站点 `public`，
  FastCGI 指向 `skiff-web-php`）并 reload；取消勾选或删除该站点时删除该文件并 reload。
- 始终保留 `00-skiff-fallback.conf`（`return 404`，不声明 `default_server`，`server_name skiff-fallback`，
  靠 `00-` 前缀排在站点 vhost 之前）。**无默认站点**时裸 IP/未知 Host 回落 404；
  **有默认站点**时 `default_server` 由默认站接管，裸 IP/未知 Host 展示默认站（1Panel 行为）。
- 删除默认站点时先移除 conf 再重载，避免残留指向已删目录的 vhost。
- 单测：v3 → v4 迁移保留原站点数据；默认站点互斥切换/解除/未知域名；
  默认 vhost 内容与兜底 404 结构；网站列表渲染默认标记与切换入口。

## 网站寄宿迁到 `/www`：host 网络 + unix socket + OpenResty

数据根从 `/var/lib/skiff` 改为 `/www/skiff`，站点寄宿独立到 `/www` 下（与 nginx/宝塔同构），
nginx 容器改 host 网络直听宿主 80，PHP 只走 unix socket。WAF 本轮**只留接口不实现**。

### 布局与权限

| 路径 | 用途 | 权限 |
|---|---|---|
| `/www/skiff` | 库、`config.toml`、`plugins`、`backup` | 0711（可穿越不可列） |
| `/www/skiff/backup` | 库快照 | 0700 |
| `/www/skiff/skiff.db` | SQLite | 0600 |
| `/www/sites/<域名>/public` | 站点站点树 | 0755 |
| `/www/nginx/conf.d` | `00-skiff-default.conf`、`00-skiff-fallback.conf`、站点 vhost | 0755 |
| `/www/logs/nginx` | `<域名>.access.log` / `<域名>.error.log` | 0755 |
| `/www/certs/<域名>` | 证书目录（HTTPS 未实现，仅建位） | 0755 |
| `/www/php` | `php-fpm.sock` 宿主落点 | 0755 |
| `/www/skiff/waf/rules` | WAF 规则目录占位（不加载） | 0755 |

- `config.rs`：新增 `web_root`（env `SKIFF_WEB_ROOT` / 文件 `web_root` / 默认 `/www`），
  `default_data_dir()` 改为 `/www/skiff`；`bootstrap::prepare_dirs` 按上表建目录并设权限。
- `install.sh`：默认 `--datadir /www/skiff`、`--webroot /www`，建全套 web 目录；给了覆盖值时
  原地改写 `config.toml` 的 `data_dir`/`web_root`；`skiff.service` 的 `ReadWritePaths=/www /run/skiff`，
  去掉 `StateDirectory` 不再覆盖数据根属主。

### 容器与网络

- nginx 与 php 均 `network_mode=host`，不再有 8080→80 映射；vhost 一律 `listen 80`。
  `ContainerSpec` 新增 `network_mode` / `log_driver` / `log_max_size`（`serde(default)`）；
  插件禁止自定义 `network_mode`（策略层直接拒绝），`log_driver` 只允许 `local`/`json-file`，
  `max-size` 校验为「数字 + k/m/g」。
- 镜像改 `openresty/openresty:alpine` 固定 digest
  （`sha256:2cb90d64…3e2214a`），不再复用 1Panel 的 `nginx:alpine` tag；配置生成保持 nginx 语法。
- PHP fpm pool 由代码生成 `www.conf`（`listen=/www/php/php-fpm.sock`、`listen.group=nobody`、`listen.mode=0660`）
  挂到 `/usr/local/etc/php-fpm.d/www.conf`，vhost 固定
  `fastcgi_pass unix:/www/php/php-fpm.sock;`，不暴露 9000。
- 安装前/建站前探测 80（预留 443 列表）：`check_port_free` 绑 `0.0.0.0` 判占用，
  被占时返回 `.pid/comm` 占用进程提示，运行环境页展示；只有自家 `skiff-web-nginx` 处于
  `running` 时才跳过探测（停着/重启中仍要探测，避免「端口被占但安装报成功」）。

### 日志

- access/error 落 `/www/logs/nginx/<域名>.access.log|error.log`；容器 `log-driver=local`、
  `max-size=10m`、`max-file=3`。
- 面板站点日志页改为读宿主文件：最新 200 行、时间倒序、`q` 关键字过滤；
  内核巡检每 30s 扫描 `/www/logs/nginx`，超 10MB 做 copytruncate（同 inode 截断），
  读日志前也会补一次，不依赖宿主 logrotate。
- 删除站点时一并清理两个日志文件与 `certs/<域名>`。

### socket 收口与 80 占用复演（同日续）

- `php-fpm.sock` 从 0666 收到 **0660**：pool 写 `listen.owner=root`、`listen.group=nobody`
  （gid 65534，openresty worker 与 php 镜像都带该组），内核在 php 容器启动后等待 socket 出现，
  再 `chown(0, 65534)` + `chmod 0660` 并复核 mode；任一步失败即安装失败，不用 0666 兜底。
- 新增单测：pool 文案不含 `0666`、`SOCKET_MODE` 为 0660 且 others 位为 0、停止/重启中的
  nginx 容器不会抑制端口探测。
- 上机实测：`stat -c '%a %U:%G'` → `660 root:nogroup`；`setpriv --reuid=12345 --regid=12345
  --clear-groups` 连接 socket → `PermissionError [Errno 13]`；站点仍 200 + `PHP Version 8.5.12`，
  面板日志页正常。
- 80 占用复演：停 nginx 容器，`python3 -m http.server 80`（pid 33620）占用宿主 80；面板触发
  「安装/重启运行环境」→ 步骤 0「检查 Docker 与 80 端口」失败，页面明确显示
  `宿主端口 80 已被占用（pid 33620 python3）…`，未拉镜像、未重建容器（无半装）。
  释放端口、删除停止的 nginx 容器后重新安装 → 两容器 Up、socket 660、裸站 200 + 8.5.12、

- 顺带修为：探测跳过的条件从「存在同名容器」改为「自家 nginx 处于 running」，避免容器停着/
