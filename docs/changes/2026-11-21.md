## 架构复审（第三轮）：复用面收口 + 静态产物清理

**背景**：延续 2026-11-19 的内核架构体检（`docs/impl/KERNEL_ARCH_AUDIT.md`），本轮复扫模块划分 / 职责边界 / 依赖关系 / 复用性 / 过度设计，只处理小问题，需要决策的挂账。

### 1. 复用面收口

- `crates/web/src/handlers/ui/containers.rs`、`ui/runtimes.rs`：手写的内存 keyset 分页改走 `ui::paginate`，与作业/资源/任务列表同一实现；`ui/mod.rs` 新增 `clamp_limit`，`page_limit` 改为它的薄包装，非 `ListQuery` 形态的列表不再各写一遍 `unwrap_or(...).clamp(...)`。站点列表因按 `(created_at, id)` 倒序、游标是「严格小于」语义，保留自有逻辑并补注释说明为何不复用。
- `crates/app/src/sites/spec.rs`：新增 `runtime_container_name_for(kind, name, id)`，把「已接入类型用 `skiff-<kind>-<name>`、未接入类型用 `skiff-runtime-<id>` 占位」收成一处；`sites/runtime.rs` 的读模型与 `web/handlers/ui/overview.rs` 的概览计数同调它。**顺带修口径缺陷**：概览原按 `kind == KIND_PHP` 自判「已接入」，Node/Rust 环境恒被算成「未安装」，现与读模型一致。
- `crates/web/src/handlers/ui/settings.rs`：主题保存、公钥导入、公钥撤销三处写入口不再内联 `user.can(Admin)` 拦截，改走 `crate::authz::authorize` / `authorize_for`，与 `authz.rs` 声明的「授权唯一入口」一致（动作表已有 `SETTINGS_KEY_IMPORT` / `SETTINGS_KEY_REMOVE`）。
- `crates/web/src/lib.rs`：删除 `pub use skiff_app as state;` 路径别名（42 处调用改写成 `skiff_app::*`），层归属在调用点可见；`AppState` / `CurrentUser` / `WebConfig` 仍对外再导出，集成测试接口不变。

### 2. 审计来源

### 3. 静态产物与构建脚本

- `crates/web/build.rs`：新增孤儿 `.gz` 清理——本轮未生成 `.gz` 的源文件（已删除、或改成已压缩格式）对应的旧变体一并删掉，避免「源码删了、预压缩残留」继续被嵌入。
