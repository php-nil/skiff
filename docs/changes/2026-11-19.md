## 新建 PHP 环境可选 apk 源 + 软件源插件复查

### 17. 新建 PHP 环境支持选择软件包源（apk）

- **改了什么**：
  - `POST /ui/v1/runtimes` 新增 `apk_mirror` 字段（DTO → `commands::runtime::CreateRuntime` 透传）；`GET /ui/v1/runtimes/catalog` 增加 `apk_mirrors` 候选与 `apk_mirror_current`（`fixed / base / label`）。
  - 运行环境新建弹窗增加「软件包源（仅 PHP 生效）」下拉：默认「自动（实测择快）」；已固定源时预选该源，自定义源自动补进候选；`kind` 非 `php` 不提交该字段。
  - SSR 兜底提交路径解析同名 `apk_mirror` 表单字段（无字段 = `None`，不改动）。
  - 内核启动 `prepare_dirs` 创建 `<web_root>/runtime/cache/apk`。
- **为什么**：源选择原先只能在安装完成后经 `com.skiff.sources` 插件生效；首次装 PHP 若没提前选源，90 MB 构建工具链仍走默认源（国内实测 535 KB/s → 30 分钟超时）。该缓存目录同时是插件 `path:` 授权根——根不存在时授权会被丢弃，插件在首装运行环境前无法写源缓存。
- **测试同步**：`runtime_catalog` 新增归一化/固定态往返单测；`web/tests/main_flow.rs` 新增目录接口与非法源拒绝用例。
- **验证方式**：`cargo fmt --all --check` + 根 workspace / `plugins` 双 workspace clippy `-D warnings` + `xtask check` 全绿；用例交 CI。

### 18. 软件源插件（`com.skiff.sources`）复查与修复

- **改了什么**：
