## AGENTS.md 由模板填充为仓库规范

- **背景**：`AGENTS.md` 原为三级文档体系模板（占位符未填、文档索引指向不存在的 `docs/project.md`），无法承担「任务执行前必读」的职责。
- **变更**：
  - 一、项目概述：填入 Skiff（轻舟）核心定位——三核心（Web 管理服务 / Docker 管理 / 插件体系）、宿主能力走插件层、主形态 systemd 直装 + 1Panel 可选受限 Docker 包。
  - 二、仓库结构：按实际目录重写（`crates/`、`xtask/`、`deploy/`、`docs/`、`.github/workflows/`），标注 gitignore 本地目录不得入库。
  - 三、全局约定：交付门槛落到具体命令（fmt / clippy `-D warnings` / test，口径与 `docs/CI.md` 对齐）；新增四条红线（分层禁令、协议/判定/分发单一来源、数字纪律、0711 权限口径）；测试要求按 Rust workspace 实况改写（`crates/<name>/tests/`、`cargo test -p skiff-policy` 快速回归）。
  - 四、文档索引：指向真实文档（`docs/DESIGN.md`、`docs/sections/`、`docs/ARCH_REVIEW.md`、`docs/DEPLOY_TEST.md`、`docs/CI.md`、`docs/changes/`）。
  - 五、变更记录：明确本目录（`docs/changes/`）承载详细变更，`DESIGN.md` 变更记录只留设计正文结构性变化。
  - 顶部新增执行约定：**任何任务动手前必须先阅读 `AGENTS.md`**，再按文档索引选读专项文档。
- **影响**：纯文档变更，无代码改动，不触发 CI（`docs/**` 在 `paths-ignore` 内）。
- **后续**：子项目（crate）如需独立规范，建 `crates/<name>/AGENTS.md` 并在「二、仓库结构」登记入口。
