## 壳层 chrome：隐藏右侧顶部通栏，改内核三级路径条（D17）

- **背景**：顶栏（品牌 / 标题 / 账号 / 退出登录）与原生面包屑重复承担「我在哪」，三级位置无处安放；产品口径定为「顶栏隐藏，由内核提供三级菜单的 UI 呈现」（决策 D17，见 [`08-DECISIONS.md`](../sdui/SDUI_BUDDING_INTEGRATION/08-DECISIONS.md) §8.1.1）。
- **壳 schema**：`shellSchema` 改 `bar: false`，`actions` 槽清空；`.bud-admin__crumbs` 在 `skiff-shell.css` 整体隐藏（1.8.0-r7 空槽仍回落默认面包屑）。
- **三级路径条**：内核自渲染 `nav.skiff-path`（挂 `.bud-admin__main` 首子节点）——一级（分组）› 二级（页面）› 三级（子视图），每级下拉切同级；模型由 `buildNavModel` 从路由树推导（`meta.subs` 承载三级，隐藏路由按段数+字面段匹配详情页，最长前缀兜底）；重建带「路径变了才重建」闸门，防 MutationObserver 自触发死循环。样式全部走外壳 chrome 变量（新增 `static/skiff-shell.css`，`spa.rs` 壳页 `<link>` 引入，`?v=1`）。
- **三级子视图登记**：`budding-boot.js` 新增 `SUBVIEWS`（当前 `core/sites/web` → 状态 / 配置 / 日志 / 模块），子项登记为隐藏路由（不进侧栏）+ `meta.subs` 进路径条；插件多视图仍由 `pluginTabs` 页内按钮行承担。
- **账号入口迁移**：顶栏的用户名/角色与「退出登录」移入「设置」页「当前账号」区块（`settingsSchema`），退出仍走 `POST /ui/v1/session/logout` 同一 CSRF 头。
- **页面大标题去重**：与路径条重复的 `title` 一律置空（网站列表、运行环境列表/详情、Web 服务四视图、站点文件），说明文字留 `subtitle`。

## Web 服务页拆三级子视图，日志改路径取数

- `webSchema` 按 `routeParts()[2]` 分发四视图，每次只渲染当前块：`/sites/web` 状态（运行状态 + 安装进度 + 容器运维）、`/sites/web/config` 配置（主配置 + 性能参数 + 包含/站点配置）、`/sites/web/logs` 日志、`/sites/web/modules` 模块；不可用告警全视图常驻。
- 日志取数从「`?logs=1` 触发」改为**路径即视图**：进入 `/sites/web/logs` 即按查询参数取数（默认访问日志 200 行），「加载日志」把条件带回 `?type=&lines=&level=&status=&q=`；`webLogsLoad` 同步改导航路径。`GET /ui/v1/web/logs` 仍要求 `load=1` 才触碰文件，接口口径未动。
- 安装进度告警的分步日志原先挤成一段（alert 吞换行）：`.skiff-web-install` 开 `white-space: pre-line`，每步各占一行。

## 网站下四页精修（网站列表 / 运行环境 / Web 服务 / 站点文件）

- **网站列表**：工具条上移（左计数「共 N 个站点」，右「批量启停（弹窗化）/ 新建站点」），批量启停从常驻大表单收进弹窗；行操作补「详情 / 启动/停止」，时间列 `type: 'date'` 本地化；表格游标到底的「没有更多了」尾巴全局收掉（`.bud-table-load-more-end`，短列表像浮字）。
- **运行环境**：工具条同款（计数 + 「新建运行环境」弹窗上移），行操作补「详情 / 日志」直达（`/runtimes/{id}`、`/runtimes/{id}/logs`），行点击仍为快捷方式；列表 total 经 `/runtimes?limit=1` 取数。

- 验收口径：逐页桌面视口截图核对（含 Web 服务四子视图、运行环境详情），混排问题——空标签、重复标题、分步日志挤行、列表尾巴——均已消掉。
