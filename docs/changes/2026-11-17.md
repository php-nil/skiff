## testkit 迁到新壳：三个视图改随包 schema + `inspect` 结果图

- **为什么**：testkit 的定位就是给新 UI 与插件能力当探针，它若还停在 HTML/iframe，验证的就是一套面板里已经看不到的旧界面。上一轮记录的「壳内点 testkit 子视图会回落旧 SSR 工作台」这条边界本轮收口。
