## 后台端口 / 入口前缀 / TLS 可配置（含三态 Cookie）

- 配置结构（单一来源，不拆两套）：
  - `Config` 新增 `tls_enabled: Option<bool>`（三态）、`entry_prefix: Option<String>`、`tls_active: bool`；
    `FileConfig` 同步，环境变量 `SKIFF_TLS_ENABLED`（`true/false/on/off/1/0`）与 `SKIFF_ENTRY_PREFIX`。
  - `tls_enabled = true` 必须有 `tls_cert`/`tls_key`，缺失拒绝启动且报错可读（指出字段、提示改 `false`）；
    `tls_enabled = false` 直接明文，不读证书、不生成自签；不写 = 旧行为自动推断（loopback / 反代 / 拒绝裸奔）。
  - 入口前缀显式值（config / env）优先并同步库；未配时首启随机 8 位落库。已有部署不改入口。
- 三态 Cookie（`crates/identity` 侧按 `dev_http` 判定）：
  - TLS 开启 / 反代终止 TLS：`__Host-skiff_session` + `Secure`（不变）。
  - 直接明文（`tls_enabled=false`）：`skiff_dev_session`，无 `Secure`、无 `__Host-`，HttpOnly/SameSite 保留；
    浏览器 HTTP 下登录、改密可走通，不再依赖反代/转发进程。
  - `allow_insecure_http` 语义收窄为「直接明文监听」；`trusted_proxies` 仍是「反代终止 TLS 时采信哪些 peer 的
    `X-Forwarded-*`」。显式 `tls_enabled=false` 时两者不参与判定。
- 启动与页面：明文非 loopback 时日志打一行「明文 HTTP 监听：Cookie 已降级，仅限内网或反代之后」，
  设置页显示醒目告警；启动地址 scheme 由 `tls_active` 决定。
- 设置页（「设置 → 后台端口 / 安全入口 / TLS」，仅管理员）：
  - 读取/修改 `listen`、`entry_prefix`、`tls_enabled`、`tls_cert`、`tls_key`，POST 保存写回 `config.toml`。
  - 端口 1–65535、`TcpListener::bind` 占用探针（同当前监听视为自己占用）；前缀 6–32 位 ASCII
    字母/数字/`-`/`_`、首字符字母或数字、不得为 `/`、保留段（`api`/`healthz`/`static`/`assets`/`favicon.ico`/`robots.txt`）。
  - 写盘：按 key 原位替换、去重复键、`toml` 解析复验、临时文件 rename；保留注释与其他字段。
  - 生效方式：**重启生效**，页面明确提示，不静默失败。
  - 防锁死：旧前缀 24h 内 GET 302 到新前缀（`settings.security.entry_prefix_previous` +
    `..._previous_until`），窗口外 404；新前缀始终可用。
- 安装脚本：`--tls on|off`、`--tls-cert`、`--tls-key`、`--no-tls`、`SKIFF_TLS`；on 时复制证书到
  `/etc/skiff/tls/`（0600）并写 `tls_enabled=true`，缺证书可读报错；off 写 `tls_enabled=false` 并告警。
  `systemd` 的 `ReadWritePaths` 补 `/etc/skiff`，否则设置页写不回配置。
- 涉及文件：`crates/core/src/{config,server,main,bootstrap}.rs`、`crates/app/src/{lib,panel_settings}.rs`（后者新增）、
  `crates/web/src/{lib,middleware,handlers/settings,templates}.rs`、
  `crates/web/templates/settings.html`、`deploy/{install.sh,config.toml.example,systemd/skiff.service}`。
- 验证：`crates/core` 新增 `tls_enabled_without_cert_fails_readably`、
  `tls_off_allows_lan_plaintext_and_downgrades_cookie`（断言两种 Cookie 名）、`invalid_entry_prefix_fails_startup`；
  `crates/app/src/panel_settings.rs` 覆盖前缀合法/非法/保留段、端口 0、占用检测、保留注释/去重、父目录不存在。
  门禁命令与结果见文末「验证」。
