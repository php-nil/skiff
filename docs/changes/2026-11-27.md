## 四、还原后新一轮上机：站点生命周期误用「重启容器」而非 reload（已修）

**背景**：测试机还原后按「重新发版 → 干净首装 → 装插件/建环境/建站 → 全量测」跑一轮。首轮回归 `round.sh` 106/0、`round_ext2` 20/0、`accept.sh` 50 PASS/0 FAIL/2 SKIP、浏览器 44 路由 44 PASS；`round_ext.sh` 露出 `S06-别名生效` 失败。

**根因**：增删站点别名走 `apply_site_aliases`，它调的是 `restart_nginx()`（**重启容器**），不是注释与契约要求的 reload。实测：加别名后**首个** `curl`（Host 指向别名）直接 `curl: (7) Failed to connect to 127.0.0.1 port 80`；`docker inspect` 的 `StartedAt` 每次都变（`04:32:07Z` → `04:32:13Z`），即整个 nginx（含**其它站点**）在窗口内不可服务。

同类误用还有四处（都属"配置已写好，只需让 master 采纳"）：`create_site`、站点启停 `set_site_running`、默认站切换 `write_default_conf` / `remove_default_conf`、删站 `delete_site`。日志里同一台机器上 vhost 保存路径打的是「nginx 已平滑 reload（worker PID 换代）」，证明 reload 在这套 OpenResty 容器上是可用的——差别只在调用点选错了方法。

**改法**

- 新增 `AppState::activate_nginx()`：取 `nginx_write_lock` → `activate_with`（reload 优先，reload 不生效才回退重启），返回 `Result<(), SiteError>`；调用方不必区分走了哪条。
- 五处"应用配置"改调 `activate_nginx()`；**回滚**路径仍是 `restart_nginx()`（回滚后必须强制把旧配置拉起来，语义相反，不能换）。
- `apply_site_aliases` 的「写 vhost → `nginx -t` → 生效」收进同一把锁（原来 `validate_nginx()` 与 `restart_nginx()` 各取一次锁，中间可被别的写入插队）。
- `create_site` 补 `nginx -t`：原来是「写完直接重启」，坏 vhost 只能靠容器起不来兜底；现在与 `set_site_policy` / `apply_tls` 一致（写 → 校验 → 生效）。
- 副作用（有意）：nginx 容器**未运行**时建站从"顺手把容器拉起来"变成"报『nginx 运行环境未启动，无法校验配置』"——与 `set_site_policy` / `apply_tls` 早已如此的口径对齐。

**未改**：nginx **主配置**保存（`crates/app/src/nginx.rs`）仍走重启。它带 300 ms 起的启动核对与回滚链，且 `worker_processes` / `worker_rlimit_nofile` 这类指令 reload 语义与重启不同，本轮不动；要改需单独一轮验主配置各指令。

**验证**：`fmt` + `clippy -p skiff-app --all-targets -D warnings` 通过；行为验证在上机（本地脚本加了 `S17-别名走reload`：`StartedAt` 不变 + 动作后首个 curl 200）。用例交 CI。

**顺带记两条操作口径（非缺陷）**

- CLI `skiff plugin install` 不通知运行中的服务：manifest `[[task]]` 要到下次服务启动才种入（契约 `KERNEL_SCHEDULER_CONTRACT/03-API_SCOPE.md` §86 只承诺「启动装配与 Web 安装/升级成功后」）。所以本轮先装插件、再 `systemctl restart skiff`，`plugin:com.skiff.monitor:sample` 等 3 条任务才出现在任务中心。
- 建站/装环境的入口参数：`proxy_target` 必须带 `http://`（`shape.field` 400 拒）；`POST /ui/v1/runtimes` 的 `kind`+`version` 才建实例，`GET /ui/v1/runtimes` 里 `version` 是目录版本、`version_display` 才是镜像真实补丁号（列表断言要用后者）。
