# 9. 里程碑

**当前进度**：M0–M4 的**代码面**已完成（三核心落地，`cargo test --workspace` 149 项全绿），但 M1/M2/M4 的**架构原型与 Linux 真机验收尚未执行**——下表「通过标准」多数仍是待验状态，不代表已达成。M5 未开始。

| 阶段 | 交付 | 通过标准 |
|---|---|---|
| M0 | workspace + `/healthz` + 静态托管 + CI + **发布包验签与 install.sh 真实机器装上跑起来** | `cargo build` 零警告；发布包摘要/签名校验通过；systemd 直装后能打开静态入口或登录页 |
| M1 | **Web 管理服务**：登录/会话/安全入口/TOTP + RBAC + 审计 + HTTPS/可信反代；并跑 **§10.1 架构原型 A 组**（#16 landlock 地基、#12 独立 UID + 授权目录、#4 路径校验 TOCTOU） | 爆破、伪造 `X-Forwarded-*`、CSRF、越权与审计用例通过；远程明文 HTTP 默认不可用；**A 组 3 条原型通过**——任一条不通过即冻结 M2/M4 中依赖它的能力，先改架构再继续 |
| M2 | **Docker 管理（基础档）**：容器/镜像/网络/卷/日志流 + exec 终端；**架构原型 B 组**（#15 grant 绑定语义、#18 迁移可回滚边界） | 动词 + 资源对象 + 参数字段三层策略对测试身份生效；Skiff/1Panel 保护对象不可被越权；WS Origin/短期票据通过；exec hijack 流可用且断连回收；**B 组 2 条原型通过**（见 §9.1） |
| M3 | **Docker 管理（生命周期档）**：Compose 明确子集 + 路径/卷校验 | 未支持 Compose 字段显式报错；越权对象与参数字段 403；local volume bind 变形被拦截；受限 Docker 形态 bind 全拒绝；与 1Panel/宝塔同机共存不冲突；自建容器不打 `createdBy: Apps` label |
| M4 | **插件体系** + 安全解包/签名安装 + 权限 UI + **fs/net 白名单** + Nginx 示范插件；**架构原型 C 组**（#17 nftables 出网收口） | `kill -9` 插件面板 100% 可用；越权 403 + 审计；自引用/重复路径/链接/解压炸弹包拒装；恶意插件用例（伪造 postMessage / 直连 docker.sock / 读 skiff.db / 越权 fs / 未授权出网）被挡；独立 UID、landlock/cgroups/pids/CPU/FD 限额实测；UI + CLI 安装、迁移失败恢复、降级沙箱显式开关实测通过；**C 组原型通过**（见 §9.1） |
| M5 | 双架构二进制 + 安装包 +（可选）Docker 包 + 备份恢复演练 | 发布包摘要/签名校验通过；真实机器安装成功 + 共存实测（不接受“应该可以”）；从备份恢复到新环境并核对核心/插件数据；**回填 §7 全部数字**（闲置口径） |

**把“装上跑起来”提前到 M0**：打包/安装细节的失败风险最高，越晚发现越贵。

**MVP 边界**：Web 管理服务 = M0+M1，Docker 管理 = M2+M3，插件体系 = M4——**三块核心跑通即 MVP**；M5 是发布硬化，不算核心缺口。fs/net 能力的官方插件（文件管理器/防火墙）排在 MVP 之后，机制在 M4 就位。

## 9.1 架构核实门

§10.1 的 6 条原型不是「有空再做」，各自挂在一个里程碑上，作为该阶段的**硬门槛**：不通过则不进入依赖它的能力编码。

| 里程碑 | 原型（§10.1） | 通过门槛 | 不通过的处理 |
|---|---|---|---|
| M1 | #16 landlock 隔离地基 | 目标发行版矩阵下三个恶意用例全部被挡：读其他插件 `data/`、写宿主其他路径、UDP 外联 | 隔离主力换成「独立 UID + 0700 目录」，landlock 降为加固；出网另设收口机制 |
| M1 | #12 独立 UID 与授权目录 | 非 root 授权目录走通「授予 → 写入 → 撤销」，撤权后写入被拒；目录重建后 ACL 行为明确 | 权限模型增加 ACL 生命周期管理（`setfacl` 授予/撤销/重建重放） |
| M1 | #4 路径校验 TOCTOU | 竞态用例（校验后中间目录换成 symlink）被挡；四种 named volume 变体判定正确 | 路径下传改为 fd 传递；补最低内核版本与发行版支持矩阵 |
| M2 | #15 grant 绑定语义 | 「授予既有容器 → 容器被删重建 → grant 失效而非误放行」；插件给自建容器打 `io.skiff.owner=<self>` 被拒 | grant 改绑稳定标识（项目名 + 内容哈希），粒度必要时收到项目级 |
| M2 | #18 迁移可回滚边界 | 「先改外部资源再迁移失败」的插件能回到升级前状态，或按声明被禁止自升级 | manifest 增「迁移可回滚性」声明，不可回滚插件只许停机升级 |
| M4 | #17 nftables 出网收口 | 与 ufw、firewalld 共存（含一次 reload）规则不丢；域名解析路径明确 | 内建 DNS 代理，或强制插件只用 IP；规则生命周期归 Skiff 独占 |

> M1 这三条与 Web 管理服务并行做，不排在其后——它们决定 M2（挂载路径校验）与 M4（插件沙箱）的实现基础，晚做等于返工。
